它解决什么问题

这四个问题，纸质笔记和 docx 都答不上来——因为它们记不住「这条信息来自哪里」。

「这个配角上次出场是第几章？」

每个实体都有出场记录，按章排列，点一下就跳回原文。

「A 和 B 到底是什么关系，我当时怎么定的？」

[[双链]] 是关系的唯一真源，两边卡片永远同步，不会各说各话。

「第 3 章埋的伏笔，第 27 章收掉了吗？」

伏笔单独建档，埋设章、预计回收、当前状态一目了然。

「这个门派的名字，第三章和第七章写得一样吗？」

全文检索 + 出处指纹，改名、合并、冲突检查都有据可依。

功能一览

不是"能记笔记"，而是按长篇写作的真实流程设计的。

🗂

实体卡片库

人物 / 地点 / 势力 / 机构 / 物品 / 概念 / 境界 / 方法论 8 种内置类型，每本书还能加最多 16 种自定义类型。

🔗

双链关系

关系只在一处定义，改一处两边更新；关系网与三维力导向视图随时看全局。

🗺

地理观地图

一层一张图：目录树收纳 + 门户互连。凡界、神界、地狱是并列的三张图，不是硬套父子。

📍

出处永不丢

每条信息都带 章节 + 段落 + 录入方式 + 时间 + 置信度。

🪶

伏笔看板

埋设、预计回收、状态跨章追踪，不怕埋了忘收。

✨

AI 抽取（可选）

用你自己的 API key，只读正文、永不代写。抽出的结果先进「待确认清单」，人工点头才落盘。

🕘

快照与回滚

删除、合并前自动快照；定时快照；误删可整本回滚。

📚

多书并行

多本书互不干扰，每本独立的类型体系、外观与配置。

🔍

全文检索

SQLite FTS5 中文检索，上千实体也不卡。

🧩

自由布局

面板想怎么摆就怎么摆，并保存成自己的布局预设。

🎨

外观与样式包

界面主题 + 图上节点样式分开管；颜色、连线、布局都能调。

📱

手机访问

同一 WiFi 下用手机查设定，写稿时不用切窗口。

界面一览

点任意一张图可放大。

设计原则

这个工具立在几条不太容易妥协的规矩上。它们决定了它能做什么，也决定了它不做什么。

正文只读

工具绝不生成、续写、改写正文一个字。AI 只负责"读"。

索引零独占状态

索引只是 markdown 的派生数据。删掉索引全量重建即可，书还在。

出处永不丢失

没有出处的设定不可信，所以每条信息都必须能指回原文。

程序目录 ≠ 数据目录

升级、重装、卸载都不碰你的书。卸载默认保留数据。

AI 永远只提议

AI 抽出来的东西先进待确认清单，人工点头才写进档案。

你的数据是你的

你录入的正文、实体、笔记，权利完全归你。
